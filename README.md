# 📊 Banking Marketing Funnel & Conversion Analysis Dashboard

This project is part of my Data Science & Analytics Internship Program.

## 🔍 Project Objective

The goal of this project is to analyze customer conversion behavior and marketing funnel performance using banking campaign data.

The dashboard helps identify:

* Funnel drop-off stages
* Customer conversion trends
* Best-performing marketing channels
* Customer engagement insights
* Business recommendations to improve conversions

## 📈 Dashboard Features

### Page 1 — Marketing Funnel Overview

* KPI Cards
* Funnel Analysis
* Campaign Performance
* Monthly Conversion Trends
* Geo Analysis

### Page 2 — Conversion Insights

* Lead Drop-Off Analysis
* Customer Segmentation
* Contact Method Analysis
* Heatmap Visualization
* Business Recommendations

## 🛠️ Tools Used

* Microsoft Power BI
* Data Visualization
* Marketing Analytics
* Funnel Analysis

## 💡 Key Insights

* Major drop-off occurs between lead qualification and conversion stages.
* Certain contact methods generate higher customer engagement.
* Campaign duration impacts conversion success.
* Customer segmentation helps identify high-converting audiences.
